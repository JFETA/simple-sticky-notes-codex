# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and semantic versioning.

## [Unreleased]

## [0.2.0] - 2026-09-23

### Added

- Markdown de Codex convertido a RTF al crear notas, con opción de texto literal.
- `format_note` para reformatear notas existentes con comprobación de contenido y respaldo.
- Formato RTF explícito `rich_json` y `format_rich_note` para fuentes, tamaño, color, resaltado, alineación e interlineado.

## [0.1.0] - 2026-09-23

### Added

- Local MCP tools for reading, creating, moving, and starring notes.
- Notebook creation and request-ID idempotency.
- Graceful application shutdown, timestamped backups, transactional writes, integrity checks, and restart.
- Codex skill, Windows installer, tests, and plugin metadata.
