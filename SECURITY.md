# Security Policy

## Supported version

Security fixes are provided for the latest release on the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's **Report a vulnerability** option in the Security tab to submit a private security advisory.

Include the affected version, reproduction steps, expected impact, and any suggested mitigation. Avoid attaching real `Notes.db` files or personal note content. You should receive an initial response within seven days.

## Sensitive data

This project runs locally. Diagnostic reports and issues must not contain note contents, database files, access tokens, usernames, or absolute user-profile paths.
